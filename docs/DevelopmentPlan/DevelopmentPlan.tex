\section{Expected Technology}

This list outlines the technologies we currently expect to use for the project. These choices may change as development progresses.

\begin{itemize}
\item \textbf{React.js + TypeScript} $\rightarrow$ Used to build the frontend and provide type safety.
\item \textbf{Vite} $\rightarrow$ Frontend build tool and development server for the React application.
\item \textbf{Tailwind CSS} $\rightarrow$ CSS framework for styling the frontend application.
\item \textbf{Python + FastAPI} $\rightarrow$ Used to build the backend REST APIs and application logic.
\item \textbf{MongoDB} $\rightarrow$ Database for storing course information, assessments, learning objectives, and CEAB-related information.
\item \textbf{Ruff} $\rightarrow$ Python linter and formatter following PEP 8 conventions.
\item \textbf{ESLint + Prettier} $\rightarrow$ Tools for identifying issues and maintaining consistent formatting in the frontend.
\item \textbf{Pytest} $\rightarrow$ Testing framework for backend unit and integration tests.
\item \textbf{Vitest/Jest + React Testing Library} $\rightarrow$ Tools for testing React components and frontend functionality.
\item \textbf{GitHub Actions} $\rightarrow$ CI tool for automatically running tests, linting, formatting, and coverage checks.
\item \textbf{Git + GitHub} $\rightarrow$ Version control and collaborative code management.
\item \textbf{GitHub Projects} $\rightarrow$ Kanban board for organizing and tracking project tasks.
\item \textbf{Visual Studio Code} $\rightarrow$ IDE for development.
\item \textbf{Docker} $\rightarrow$ Used to containerize application components and maintain consistent development environments.
\end{itemize}
